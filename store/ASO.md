# Mochi Pop: Play Store search optimization

Paste-ready text is in `store/listing.txt`. This file explains the choices.

## Target keywords
Google Play indexes the title (strongest), short description, then full description. There is no hidden keyword field.

| Priority | Keyword | Where it appears |
|---|---|---|
| 1 | block puzzle | title, short, full (2x) |
| 1 | block puzzle game / puzzle game | short, full |
| 2 | cute / kawaii | title, short, full |
| 2 | offline game, no wifi | full (section header) |
| 2 | relaxing | short, full |
| 3 | block games, brick puzzle, line clear, brain game, combo, 8×8, time killer | full |
| 3 | pets / collect | short, full |

Rules followed (Play metadata policy): no competitor names (Block Blast, Woodoku, 1010!), no "free", "best", "#1", "top" or emoji in the title, no keyword lists, no keyword repeated unnaturally.

## Screenshot captions
Add a short headline above each phone frame (big rounded font, 2–4 words). First two screenshots matter most because they show in search results.

1. shot2-game.png: **Relaxing Block Puzzle** / "Drag, drop, pop!"

## Category and tags
